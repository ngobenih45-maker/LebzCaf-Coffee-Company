LebzCafe website
================
Files: index.html, about.html, contact.html, style.css, script.js, images/

Open index.html in a browser to preview. To publish, upload the whole folder to any web host.

Edit in script.js (CONFIG at the top):
- whatsappNumber  : 27783225938 (078 322 5938)
- hours           : opening hours per day
- messages        : the automated WhatsApp message for each button (data-wa="key")

To make any new button open WhatsApp with a message, add:
<a href="#" data-wa="order">Order</a>
